# Diff and Markdown Rouge coverage (Steps 7–9)

The baseline [`test-map.json`](test-map.json) inventories the pre-cutover tests. The replacements below are public integration tests under `crates/diff/rouge/tests/`. The exact legacy assertions remain at `09a11f7e7fbaa354a2df4743b4ee18ede000a30c` under `crates/diff/gpui/tests/`; they are not copied into the live source tree. Coverage gaps below are open, not waived by the removal.

| Legacy group | Mounted Rouge coverage | Remaining parity or verification |
| --- | --- | --- |
| `diff_view_test.rs` | `diff_view_test.rs` checks unified/split side targeting, same-count replacement, bounded mounts and first/last reveal across 100,000 code rows, fixed gutters during horizontal scroll, viewport retention across refresh, and sticky-header reveal/push-off. `keyboard.rs` covers source entry and gap expansion. `comment_editor_test.rs` checks cross-file scroll without changing the selected row or draft. | Independent diff/source scroll restoration; layout changes at deep anchors; removed-file fallback and empty state; collapsed-directory follow, collapse counts and header/gap pointer actions; wheel normalization/overscroll parity. Visual coverage for metadata, rename, binary/status-only and no-newline fixtures is still needed. |
| `comment_editor_test.rs` and comment cases in `rendered.rs` | `comment_editor_test.rs`, `keyboard.rs` and `commands_test.rs` cover inline placement, growth, Shift+Enter, immediate Escape cancel in Diff, IME Enter, add/edit/delete, blank rejection, export, and focused selection and undo/redo across compatible refresh. Scrolling far enough to unmount the row preserves the body and anchor, and clicking the editor after return resumes editing. | Offscreen unmount does not retain editor selection, undo history or focus; returning alone does not refocus.
